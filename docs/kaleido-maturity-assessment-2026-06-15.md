## 1. 整体诊断：线性流水线是错误的形状

最深的问题不在任何单个模块，而在**范式本身**：当前产品是"选模板 → prepare → 跑 N 轮 → 出报告"这条**单向、一次性、不可逆的预测流水线**。这个形状与"关系探索"定位在根上冲突。

证据是连贯的，而且全部指向同一个病灶——**每一站都在生产"看起来专业的空数据"，而下一站并不真正消费上一站的产出：**

- M1 接地层算出 WorldCover 像素，但 region 的 `land_use_class` **9 个全空**，没人消费；
- M3 Zep 在 envfish 主路径**根本不建图**（`simulation.py:2176` 强制 `enable_graph_memory_update=False`），建了也读不出来（reader 返空）；
- M6 的 14 个 hazard 模板坍缩回 4 个 legacy 桶，`impact_chain`/`secondary_channels` 是**死字符串**，全仓只在定义处出现；
- M7 的机制图（25 种关系、正确时滞）写盘即冻结，**从不进入物理回路**（grep `run_envfish` 零引用机制图），`contaminant_concentration` 等 LLM 自创变量无 engine 绑定 → 整局为 `None`；
- M5 的风险分在 5 轮里恒等（68.4/0.88/92），tracker 不读状态矩阵；
- M8 的关系 strength **从不回馈任何 state_vector**，边"创建—消亡—重建"地抖动；
- M10 的回放 `animation_progress = (elapsed-delay)/window`，是**时间编排的淡入**，不读状态向量。

**结论：整条管线是一台没有反馈环的传送带。** 它装着预测器的骨架，挂着探索器的招牌。关系探索的本质是**交互式、可逆、由用户扰动驱动**的——"如果切断这条边会怎样？""为什么这两个区域会耦合？"——这些问题没有一个能被"跑 N 轮出报告"回答。

## 2. 关于"Zep 多 agent 架构是否被抛弃"——必须澄清的误解

**你的直觉对一半，且这一半至关重要：多智能体关系演化是核心，绝不能丢，而且要加深。**

但有一个事实你需要知道：**这个核心当前并不跑在 Zep 上。** M3 的证据是决定性的——

- `simulation.py:2176` 对 envfish 引擎**强制关闭** Zep 图记忆写回（覆盖前端的 `true`）；
- 真实 run 的 `graph_id = "mapseed_..."`，是地图种子 id，不是 Zep `graph.create` 出的图——**这次真跑根本没建 Zep 图**；
- `zep_entity_reader` 三个方法全部返回空，`zep_graph_memory_updater` 是 `_NoopUpdater`，`zep_tools` 的 GraphRAG 全部改读本地文件。

**真正的关系演化核心在别处**：`run_envfish_simulation.py` 的动态边生命周期 + `mechanism_simulation_service.py` 的因果图。它们带方向/时滞/尺度/证据，**完全绕开 Zep**。

所以正确的表述是：
- **"保留多 agent 关系演化核心" = 保留并加深 M7 + M8，而不是保留 Zep。**
- **Zep 具体这套集成是死重量，可以砍掉而不损失任何核心能力。**
- 关系核心确实**需要一个时序图底座**（记录"某关系第 N 轮激活/失效"）——这本该是 Zep 双时态图的用武之地，但当前集成没在做这件事。要么把 Zep 真正接通来承载它，要么用一个更轻的本地时序图。当前状态是"两者都没有，靠手搓 jsonl ledger"。

## 3. 逐模块评估

> 每张卡：成熟度 → 现状（带证据）→ 核心缺陷 → 重新构想 → 工作量。完整 800 字版见本次评估的 agent 原始输出。

### M1 空间接地层 — 38%
**现状：** 存在两条互不相通的路径。富管线 `map_seed_manager.py`（2807 行）确有 Nominatim/Overpass/WorldCover-2021/Open-Meteo 四个真实数据源；但模拟主路径在 `env_profile_generator.py:197-198` 直接用 9 行空桩 `PublicDataGroundingService`/`TransportContextResolver`（永远返回 `local_fallback`）。区域命名靠写死的深圳/武汉 gazetteer（`_local_geographic_candidates` L939、`_wuhan_curated_features` L1635）。
**核心缺陷：** ①接地与模拟解耦＝假接地；②地理覆盖只有深圳+武汉，出城断崖；③WorldCover 是 2021 静态年快照，对时变情景无时间维；④"区域"是 LLM 想象的名字+坐标，无真实边界/人口；⑤无 provenance 分级。
**重新构想：** 删桩接通真管线（1 天）；WorldCover 像元统计直接填 region 状态初值；数据模型加 `provenance{source,confidence,is_static}` 一等公民；用 Overpass 行政边界替代写死 gazetteer，脱离深圳/武汉。
**工作量：高｜5-7 天。**

### M2 场景素材生成 — 38%
**现状：** compose 流程完整（`scene_material_generator.py:259`）。但"只放扰动"的变量纪律**只活在 system prompt 文本里**，代码侧唯一守卫 `_is_baseline_context_variable`（L82-117）只拦"天气基线"一种伪变量。fallback 是 15 段硬编码模板（L511-655），关系网络三行写死。
**核心缺陷：** ①变量纪律是幻觉；②fallback 制造"看起来专业的空报告"，污染下游抽取；③事实/推断/假设三分无机器保障；④稳态与扰动挤在同一个自由文本框；⑤无 token 预算守卫。
**重新构想：** 输入改**显式双轨**——稳态轨（产出 observed/inferred 双色关系图草稿，每条边带 evidence_source）+ 扰动轨（每个变量强制四元组 `{target_node, direction, magnitude, time_window}` 且必须指向已存在节点＝缺失的接地闸）。fallback 改"诚实骨架"而非伪专业模板。
**工作量：高｜8-10 天**（先做变量轨接地闸，3 天见效）。

### M3 Zep 图谱与本体抽取 — 12%（全系统最低）
**现状：** `ontology_generator.py` 14 行写死返回 Region/Actor/Risk + AFFECTS/LOCATED_IN，日志却谎称"调用 LLM 生成本体"（`graph.py:215`）。`zep_entity_reader` 三方法返空，`zep_graph_memory_updater` 是 Noop，`zep_tools` GraphRAG 改读本地文件。生产路径建图即弃（见 §2）。
**核心缺陷：** ①信号损失灾难——LLM 真能产 ~25 种关系，写死本体只允许 1 种 `AFFECTS`；②Zep 建了即弃；③GraphRAG 是空壳剧场；④日志/命名集体撒谎（最危险的债）；⑤两套关系系统并存不互通。
**重新构想：** 杀死本体 stub，让本体由场景 LLM 现生成，**核心是"关系类型"**（channel/direction/latency/scope/loop_role/leverage/evidence/provenance——这正是 `validated_relation_graph` 已有的字段）。统一到一张时序关系图，用双时态承载"关系演化"。GraphRAG 改真图算法（找反馈环、高杠杆边、跨区传导路径）。
**工作量：高｜6-9 天。**

### M4 Agent / 区域生成 — 33%
**现状：** 两条路径。真实深跑走 entity_template 路径，结果 **25 个 profile 全是 `human/resident`**，persona 却在写"生态规划师""一片水体"——病根在 `_agent_identity`（L3525）兜底 `return ("human","resident")`，且 persona 与 agent_type 由两套逻辑各写各的。关系种子 `_build_agent_relationships`（L3048）是纯模板、写死强度、且在 `simulation_manager.py:526` **被整体丢弃**。地图证据门（`_review_map_agent_candidate` L2069）是真接地，但只覆盖少触发的 map_seed 路径。
**核心缺陷：** ①身份坍缩（24/25 居民）；②接地门旁路；③关系种子是装饰且是死代码；④4 类分类法不适配人-自然耦合（缺基础设施/制度/过程）；⑤大量 magic 阈值无出处。
**重新构想：** 取消二路径，统一"证据→候选→批判→接地标记"单管线，每个主体强制带 provenance 三态；身份由角色谱+证据联合决定，persona 与结构化字段同一次 LLM 调用自洽产出；本体扩类（actor/institution/infrastructure/ecological_receptor/process/rule）；关系即一等数据模型，与 mechanism_service 合并，删模板版。
**工作量：高｜先 6 天止血（修身份坍缩+统一接地门）。**

### M5 风险对象体系 — 20%
**现状：** `RiskDefinitionBuilder` 是纯确定性关键词模板匹配器，5 个硬编码模板（L20-71），`chain_steps`/`turning_points` 全是模板字面量。三分数是饱和计数公式（L358-375），区域多时全部撞上限——真实 run 5 个风险 `severity=68.4/confidence=0.88/actionability=92` **完全相同**，且运行时零变化。`RiskRuntimeTracker.refresh` 只重抄静态定义不读状态。`risk_events.jsonl` 为 0 字节。
**核心缺陷：** ①分数无判别力（5 个不同风险同一个数）；②运行时是死的；③链路与证据同义反复；④与物理核脱节；⑤预测者形态错配。
**重新构想：** 风险从静态评分卡 → **关系图上的涌现张力结构**。字段改为 `tension_trace`（每轮真读状态矩阵，可画线）、`coupling_edges`（引用真实关系边）、`leverage_points`（图算法得出）、`turning_points`（曲线拐点检测）。删掉三个假精确标量，改方向性张力曲线 + 不确定性带 + "是否落在反馈环上"。
**工作量：高｜先 2-3 天（让 tracker 真读状态、severity 随轮变化）。**

### M6 仿真配置 / hazard 扩散模板 — 25%
**现状：** `HAZARD_TEMPLATE_CATALOG`（envfish_models.py L290-397）有 14 个 hazard 模板，但底层只 12 个 transport family，再经 `PRIMARY_FAMILY_TO_LEGACY` 坍缩回 4 个 legacy 桶。模板间真正差异只有 4 个数字（lag/decay/persistence/max_spread）。`impact_chain`/`secondary_channels` 在动力学中**从不被消费**。选择路径是关键词正则或"让 LLM 从目录里选一个"。
**核心缺陷：** ①固定 taxonomy 与复杂性哲学正面冲突；②大部分模板内容是 Potemkin 字段；③14→4 信息坍缩使分类决策几乎无意义；④参数无溯源；⑤provider/context 契约已破（LLM 往里塞散文）。
**重新构想：** 取消"从 14 个盒子选一个"，改为**不可枚举的"扰动假设" + 可组合的"传播通道图"**。`PerturbationHypothesis`：origin_node_ids + carrier_media（多选非互斥）+ propagation_channels（有向图，每条带 mechanism/confidence/evidence，且**必须进入运行期**调制 transfer）。UI 从下拉框变成"可编辑的传播通道画布"。
**工作量：高｜先 4-6 天（让通道真进运行期+校验接地）。**

### M7 深度机制推演 — 45%（最强的一层）
**现状：** LLM 一次性产出的因果图**确实强**：地点特异（茅洲河→深圳湾→石岩水库）、时滞排序正确（immediate→hours→days）、scope 区分 local/cross_region。但 `_validate_relations`（L432）只做 schema 校验+去重，无机制/证据时**回填模板句和 `["llm_relation_candidate"]`**；`evidence_coverage=1.0` 是循环自证。真实 run 中 **19/25 条边是 fallback 模板**（76%）却仍报满覆盖。机制图从不进入物理回路。
**核心缺陷：** ①覆盖率指标系统性说谎；②机制图是装饰不是引擎；③fallback 把无知伪装成关系；④校验的是 schema 不是因果可辩护性；⑤一次性、不可反驳、不可追问。
**重新构想（这是该提为中心的一层）：** 升级为**可执行、可反驳的因果剧场**。真校验三关（方向极性一致性/证据回指/矛盾环检测），覆盖率改"端点证据来自外部源"，fallback 边标 `speculative` 且不计入覆盖。让机制边的 direction/latency/sign 成为引擎状态转移的来源（轻量符号化传播，比 0.18 魔法常数诚实）。每条边一张可反驳卡片（机制+证据锚点+置信+不确定，用户可质疑/给反例/反事实重跑）。
**工作量：高｜先 3-4 天（真校验+覆盖率诚实化，堵诚实性破口）。**

### M8 运行引擎与关系演化 — 32%（核心资产，要深化）
**现状：** 主循环逐回合跑通（L471-525），但 agent 行动是**硬编码决策树无 LLM**（`_choose_agent_action` L1450）。"关系演化"实为 TTL/衰减记账层；晋升机制要求 reconfirm≥3 但实测最大值=2，**0 条边晋升**，且默认关闭。`agent_interaction_ledger` 在真实 run 中**根本不存在**（agent 间互动为零）。dynamic_edge 的 strength 变化**从不回馈任何 state_vector**——纯装饰图层。127 事件/74 边，全是 information channel，边"创建—消亡—重建"抖动。
**核心缺陷：** ①关系是只读装饰；②真实互动为零；③抖动≠演化；④同质化（3 种 edge_type、全 information）；⑤行动决策树写死。
**重新构想（最值得投入）：** 翻转为"**关系是第一类对象，状态是关系的副产品**"。边激活时按 `strength×channel_gain` 真实传导端点状态；每条边维护 `history[]` + `tension/alignment` 对立维度（可从协同翻转为对抗）；LLM 只做一件事——解释与重写关系（relabel/leverage_hint/识别反馈环）；晋升降门槛+可视化（边变粗固化进骨架）；到期边降为 dormant 保留历史（关系有疤痕）。
**工作量：高｜11-16 天，分两批。**

### M9 报告 / 分析 / 节点探索 — 52%（最成熟，含产品灵魂）
**现状：** ReACT 报告是真实多轮工具循环（`report_agent.py:1678`），但定位成"上帝视角·未来预测报告"（与新定位冲突），且 `interview_agents`（宣传为"深度采访真实 Agent"）实际是 `zep_tools.py:82` 把 state_vector 套进固定句式的**伪采访**。narrative tab 纯模板拼接不调 LLM。**但节点探索（L1670）是 7 tab 里最扎实的**——真实多源匹配、2 跳子图、机制链回溯，且诚实标注 `source_type`（直接观测/推断/补全）和 `missing_data`。
**核心缺陷：** ①`interview_agents` 冒名顶替（把数值套话包装成"人群原话"）；②定位与新方向相反；③narrative tab 零信号；④报告与 node-explore 两套证据系统不互通；⑤节点匹配靠子串模糊匹配。
**重新构想：** 砍掉"7 个并列 tab"，重构为**单一"关系探索画布 + 证据抽屉"**（node-explore 子图为中心，feedback/narrative 降为叠加层）。报告改造为"探索轨迹报告"（记录审讯了哪些节点、发现哪些杠杆点、哪些观测哪些推断），删/改名伪采访。引入统一 `evidence_ref` 焊死两套证据系统——报告每个论断挂可点开的证据引用。
**工作量：高｜先 3 天（删伪采访+报告去预测定位+narrative 用真叙事）。**

### M10 可视化渲染管线 — 32%
**现状：** 后端把所有边一股脑展平进同一张图（实测 58 节点/≈263 边，平均度>9）——这是毛球来源。2D 力导参数对密图灾难性（263 条边无语义分层平权弹簧）。地图投影大部分是 `sha256` 哈希散点（无 map-seed 时位置零信息）。Step-3 回放是**伪状态变化**：`animation_progress` 纯时间编排，节点 status 来自编造的出场顺序，真实数值漂移（某区 vuln 75→77→79）**从未绑定颜色/半径**。
**核心缺陷：** ①同图混合不可比的边（空间事实 vs 因果关系）；②力导无结构先验必然毛球；③回放与物理脱钩；④地图退化为哈希散点却用真底图营造接地假象；⑤"风险脉冲"依赖从不写盘的 risk_events，是死分支。
**重新构想：** 三视图各司一职：结构层（地图，只画空间事实，无 seed 时禁用并标"非地理"）+ 耦合层（关系图，只画因果边，按 channel 分桶 + Louvain 社区着色 + 边折叠，263→~8 簇）。回放绑真数值（半径=vulnerability、颜色=delta、边粗=当轮是否激活）。主视图加"耦合阅读器"（激活热力弦图/矩阵，一眼看出哪条关系第几轮先动）。
**工作量：高｜先 4-6 天（社区分桶+回放绑 delta，灭毛球）。**

## 5. 理想形态：从"危机预测流水线"到"扰动-观察-重连乐器"

从第一性原理重建，Kaleido 不应是逐回合预测器，而应是一台**扰动乐器（perturbation instrument）**。核心交互环四步、可无限循环、可回退：

> **选一个网络状态 → 注入一个扰动（掐断/加压/抽离一条边或一个节点）→ 观察网络如何重连 → 在任意节点/边上追问"为什么"**

整个产品围绕**唯一一个一等原语：关系（edge）**。节点只是边的端点；风险只是一组边在压力下的张力聚集；agent 只是边的行为载体。

**中央 UI 隐喻：活的关系网络 + 扰动探针 + 时间刮擦条。** 语义分层（空间骨架边淡、因果耦合边亮，绝不同图平权）。用户拖探针到边上选择"掐断/加压/注入/抽离"，松手瞬间网络实时重连，时间刮擦条让用户前后拖看同一扰动的传播相位。

**数据模型的核心翻转：状态是关系的副产品。** 每条边是对象 `{source, target, mechanism, evidence[], latency, direction, scope, strength_trace[], activation_trace[], provenance}`，`strength_trace` 必须真实回馈端点状态。

## 6. 关系探索的诚实边界：当指南针，别当尺子

让工具**可信**的关键，而当前产品在这点上系统性撒谎（日志谎称调 LLM、coverage 循环自证、哈希散点假接地）。可辩护与否，**以断言类型为界：**

**可辩护（关系层）：**
- **拓扑** —— 谁和谁有关系（根植于真实文档/地图证据）
- **方向** —— 污染源→传输→受体，不是反过来
- **符号** —— 这条关系是放大还是抑制

**不可辩护（数值层），必须明确免责：**
- **强度数值**（strength 0.75）—— 只能用于排序，不能当概率/效应量
- **状态量级**（exposure 62、`×0.18`）—— 未经标定的规则常数
- **时间线与概率**（latency hours/days 是分类标签，不是时刻表）

> **把它当指南针用（方向对），不要当尺子用（刻度假）。**

**7 条让关系探索更深更可信的设计：**
1. **集合化（fan-of-outcomes）** —— 同一机制图跑 N 次，展示"边的出现频率"，而非单一拓扑
2. **强制双向论证** —— LLM 先为边辩护、再反驳，只有经得起自我反驳的边才高置信
3. **provenance 三态** —— observed / inferred / imagined，三档视觉分级，fallback 边虚线化
4. **涌现回路检测** —— 每轮跑有向环检测，把"恐慌→响应→摩擦→延迟→更高暴露→更多恐慌"显式抽出
5. **反事实扰动** —— "如果这条边翻转符号会怎样"一键重跑，识别结构性枢纽 vs 冗余
6. **可对质的边** —— 用户可否决/强加/调符号一条边，带约束重跑，形成假设演化史
7. **置信度去数值化** —— 不展示 `0.85`，改"由 2 条 routing + 1 机制边 + 0 文档证据支撑"

**定位语：**
> 关系探索：我们不预测系统会变成什么数字，我们用 LLM 推演关系的**结构、方向与符号**——把复杂人-自然系统里那些只能定性知道的耦合与反馈，变成一张**可审计、可争论、可重跑**的关系地图。

## 7. 给单人开发者的最小可信内核（MVP-of-the-vision）

按依赖顺序，抵制"先做 N 轮/先做报告/先碰 Zep"的诱惑：

- **阶段 0 — 一条真边：** 定义统一 edge 数据对象（source/target/mechanism/evidence/latency/direction/strength/provenance）。整个产品的地基。
- **阶段 1 — 真接地的边抽取：** 复用 M7 机制抽取 + M1 富管线真实地图证据，产出带来源标记（实线/虚线/点线）的初始关系图。**不建 Zep、不选 hazard 模板。**
- **阶段 2 — 扰动算子 + 单步重连：** "掐断一条边"或"给节点加压"，沿边做一步消息传递，下游边强度变化并**真实回馈端点状态**。与旧产品的根本分界。先单步，不做 N 轮。
- **阶段 3 — 语义分层可视化 + 扰动探针：** 空间骨架边（淡）vs 因果耦合边（亮）分层，拖探针选边掐断、观察重连。不做力导毛球，用分层布局。
- **阶段 4 — 节点/边审讯（产品灵魂）：** 移植 M9 节点探索逻辑，从"问节点"扩展到"问边"：点任意边问"你为什么存在、证据在哪、掐断你会怎样"。
- **阶段 5 — 时间刮擦条：** 单步扰动扩展为可前后拖动的传播相位。

**阶段 0-2 是不可省的最小可信内核——一条真边 + 一个真扰动 + 一次真重连，就已经比当前整条流水线更诚实、更贴定位。**

---

*一句话总论：Kaleido 当前是一台戴着探索器面具的预测传送带（整体 ~33% 成熟）；真正的重构是把唯一两个真资产（M7 机制抽取、M9 节点探索）提为中心，围绕"关系=一等原语 + 扰动=交互 + 证据来源=可见"重建一台可反复拨弄的乐器，并通过对模型想象的吵闹诚实来换取信任。*
