## 1. 产品定位与功能架构（已确认）

- **定位**：复杂**关系演化探索器 / 关系探索沙盘**，**不是预测器**。方法论是复杂性生态哲学（关系一等公民、涌现、反馈环、杠杆点、不确定性即特性、observed/inferred 诚实）。
- **核心交互环**：选地点 + 描述扰动 → 系统生成一张关系图 + 风险 + 主体 → 推演看关系如何演化 → 在任意节点/边上追问"为什么"。**唯一一等原语是"关系（edge）"，状态是关系的副产品。**
- **四步流程 + 每步主任务**：
  1. **背景生成** = 选地点 + 描述扰动 + 给资料。
  2. **场景设计** = 确认参数 + 看系统生成了什么（风险/区域/主体/关系）。
  3. **推演播放** = 看关系网随扰动演化。
  4. **结果分析** = 追问关系怎么演化、哪些观测/哪些推断、杠杆在哪。
- **已确认的未来方向（未排期）**：从"单场景沙盘"进化成**跨场景积累的知识图谱**（实体/关系跨分析持久、去重、联动，成为"人-自然耦合"第二大脑 + BlueDot 内容底座）。持久层选型待定；对国内产品 Zep（美国托管）不是首选，大概率自托管图库。

## 3. 前端重设计（待做主体）

> 反馈核心：界面"乱的要死、不符合人体交互逻辑、大量容器挤压、每步一大堆内容排在一起"。诊断：**不是 100 个小毛病，是 7 个系统性病根。**

### 7 个系统性病根
1. **50/50 硬分屏** — 右栏内容压进 50% 窄列单滚动（"挤压"结构性根因）。
2. **空卡按满尺寸渲染占位** — "大量容器没内容"。
3. **同一数字重复 3 次**（状态条 + tab summary + 面板表头）。
4. **内部细节裸露**（英文 key / `dynamic_edge` / `未命名节点` / `n/a` / 源路径 / 英文状态）。
5. **说教灰字打补丁**（6+ 段长灰字）。
6. **重叠冗余结构**（Step1 四个重叠 textarea；首页两套"四步"；MainView≈SimulationView；区域矩阵渲染两遍）。
7. **离题模块占主线**（太空预测 / 3D 图谱 / 变量注入写操作）。

### 4 个已确认决策（用户拍板）
- **布局** = 图谱可折叠、内容全宽铺开。
- **空状态** = 保留现有占位卡（不藏空状态）。
- **砍/移出** = 无（功能、占位、太空预测、3D、变量注入、报告 tab 全保留）。
- **合并力度** = 激进合并（但在"不删功能"约束下 = 容器层面合并 + 渐进展开 + 全宽，不是砍内容）。

### 6 条横切规矩（应用到所有页）
1. 一个数字只显示一次；2. 内部细节永不上屏（白名单+中文）；3. 每步一个主任务、次要折叠/抽屉/tooltip；4. 图谱可折叠、内容横向铺开；5. 说教灰字→tooltip 或删；6. 保留所有功能与占位，靠**重排+清洗**去乱，不靠删除。

## 6. 重新开始：建议执行顺序（先做"看得见的大块"）

2. **逐屏标签/卡片激进合并**（Step2 → Step3 → Step4），同时把"运行态张力"移到对的页、去重计数器。
3. **Step1 输入双轨 + 合并重叠 textarea**。
4. **外壳合并 + 顶层导航清理**。
5. 收尾 bug 清单 + 节点详情进一步折叠。
6.（之后）后端 Phase C 拆 Zep / 知识图谱方向。

每屏做完 `npm run dev` 让用户亲眼确认，再下一屏。
